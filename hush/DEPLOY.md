# Как запустить hush. по-настоящему

Всё делается в браузере, без терминала. Понадобится примерно 30 минут.
В итоге получится **один сервис на Railway**: он хранит данные в базе PostgreSQL, отдаёт приложение и управляет ботом.

Стоимость: Railway — около $5 в месяц (есть пробный период). Telegram — бесплатно.

---

## Шаг 1. Бот

Бот уже создан: **@Hush_miniapp_bot**. Его имя уже прописано в приложении.

Токен бота (вида `1234567890:AA...`) BotFather прислал при создании; если потерялся — @BotFather → `/mybots` → @Hush_miniapp_bot → **API Token**.
**Никому его не отправляйте** и не публикуйте — он нужен только на шаге 3.

> Vercel не нужен: сервер на Railway сам раздаёт приложение. Так проще — один адрес, одна точка настройки.

---

## Шаг 2. Railway: проект и база данных

1. Зайдите на **railway.com** → войдите через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий `nastyabarashkovaru-gif/-`.
3. Откройте созданный сервис → **Settings**:
   - **Source → Branch**: `claude/app-and-instructions-ihq84m`
   - **Root Directory**: `hush`
   Команды сборки и запуска Railway возьмёт сам из файла `hush/railway.json` — их вводить не нужно.
4. В проекте нажмите **+ Create → Database → PostgreSQL**. Появится второй блок «Postgres».

---

## Шаг 3. Переменные

Откройте сервис приложения (не базу) → вкладка **Variables** → **New Variable**:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен из шага 1 |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` — так и впишите, Railway сам подставит адрес базы |
| `APP_SHORT_NAME` | `app` |
| `GRANT_PREMIUM_IDS` | *необязательно.* Ваш Telegram ID или @username — чтобы проверить годовой Premium и раскрытие авторов, пока оплата не подключена. Свой ID можно узнать у @userinfobot |

---

## Шаг 4. Адрес приложения

1. Сервис приложения → **Settings → Networking → Generate Domain**.
   Получите адрес вида `https://hush-production-xxxx.up.railway.app`.
2. Вкладка **Deployments** → у последнего деплоя **⋮ → Redeploy**, чтобы сервер узнал свой адрес.
3. Проверьте в браузере: `https://<ваш-адрес>/api/health` должен показать `{"ok":true}`.

При запуске сервер **сам** подключит бота: настроит приём сообщений и кнопку меню «Открыть hush.».
В логах (вкладка **Deployments → View logs**) должна появиться строка `[bot] webhook и кнопка меню → https://...`.

---

## Шаг 5. Mini App в BotFather

Нужно, чтобы ссылки на анкеты вида `t.me/Hush_miniapp_bot/app?startapp=...` открывали приложение.

1. @BotFather → `/newapp` → выберите @Hush_miniapp_bot.
2. Название: `hush.`; описание: `Узнай анонимно, что о тебе думают люди`.
3. Фото 640×360: загрузите `hush/design/botfather-cover-640x360.png` из репозитория.
4. GIF — пропустите командой `/empty`.
5. **Web App URL**: адрес из шага 4 (`https://...up.railway.app`).
6. **Short name**: `app` (как `APP_SHORT_NAME`).

---

## Шаг 6. Проверка

1. Напишите @Hush_miniapp_bot `/start` — он ответит кнопкой «Узнать, что обо мне думают».
2. Откройте приложение, выберите 5 вопросов, нажмите «Поделиться с друзьями». Разрешите боту присылать сообщения — так придёт уведомление о пятом ответе.
3. Отправьте ссылку 5 друзьям (или попросите 5 человек с разных аккаунтов). На свою анкету ответить нельзя.
4. После пятого ответа бот пришлёт «Твои ответы готовы! 💜», а в приложении откроются результаты.

## Оплата через CloudPayments

Сервер создаёт заказ и открывает виджет CloudPayments. Подписка включается **только** после уведомления
от CloudPayments с проверенной подписью — оплату нельзя подделать из приложения.

1. **Railway → карточка hush** (не Postgres!) → **Variables**:

| Переменная | Значение |
|---|---|
| `CP_PUBLIC_ID` | Public ID из ЛК CloudPayments (Сайты → ваш сайт → Настройки) |
| `CP_API_SECRET` | Пароль для API оттуда же. Секрет — никому не пересылайте |
| `CP_RECEIPTS` | `true`, если подключён CloudKassir (чеки 54-ФЗ), иначе не задавайте |
| `CP_TAXATION` | система налогообложения для чека: `1` — УСН «доходы» (по умолчанию), `2` — УСН «доходы минус расходы», `5` — патент, `0` — ОСН |
| `LEGAL_NAME` | ФИО ИП, например `Иванова Анна Сергеевна` |
| `LEGAL_INN`, `LEGAL_OGRNIP` | реквизиты ИП |
| `LEGAL_EMAIL` | email для возвратов и обращений |

2. **ЛК CloudPayments → Сайты → ваш сайт → Настройки → Уведомления.** Включите и вставьте адреса
(метод POST, кодировка UTF-8):

| Уведомление | Адрес |
|---|---|
| Check | `https://hush-production-927e.up.railway.app/api/billing/cloudpayments/check` |
| Pay | `https://hush-production-927e.up.railway.app/api/billing/cloudpayments/pay` |
| Fail | `https://hush-production-927e.up.railway.app/api/billing/cloudpayments/fail` |
| Рекуррент | `https://hush-production-927e.up.railway.app/api/billing/cloudpayments/recurrent` |

3. **Оферта и политика** уже опубликованы и подставляют реквизиты из переменных:
`/legal/offer` и `/legal/privacy` на адресе приложения. Ссылку на оферту CloudPayments попросит при подключении
рекуррентных платежей. Тексты — черновики, покажите их юристу.

4. **Проверка в тестовом режиме** (сайт в ЛК в статусе «Тест»): оплатите картой `4242 4242 4242 4242`,
любой срок и CVC. В логах Railway появится `[billing] оплачено: ... (тест)`, в приложении — Premium.
Если для вас включён `GRANT_PREMIUM_IDS`, сначала уберите его, иначе Premium уже есть и проверять нечего.

## Что работает, а что пока нет

**Работает:** вход через Telegram с проверкой подписи; анкеты; ответы друзей; порог 5 ответов; закрытые ответы на бесплатном тарифе; согласие на раскрытие и его журнал; уведомление ботом ровно один раз; защита от повторных ответов и ответа на свою анкету; лимиты запросов.

**Пока нет:**
- **Оплата** включается, когда заданы `CP_PUBLIC_ID` и `CP_API_SECRET` (см. выше). Важно: правила Telegram требуют продавать цифровые товары в Mini App за Telegram Stars; оплата картой внутри приложения — риск блокировки бота.
- **Политика конфиденциальности и условия подписки.** Нужны до публичного запуска: вы храните ответы людей и их согласие на раскрытие профиля. Ссылку на условия задайте в переменной `VITE_TERMS_URL`.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Деплой падает | Root Directory = `hush`, ветка `claude/app-and-instructions-ihq84m` |
| В логах «Не задана переменная окружения» | Variables: `BOT_TOKEN` и `DATABASE_URL` |
| `[bot] getMe не удался` | Неверный `BOT_TOKEN` |
| `PUBLIC_URL не задан` | Сгенерируйте домен (шаг 4) и сделайте Redeploy |
| Бот молчит на `/start` | В логах должна быть строка про webhook; после смены домена — Redeploy |
| В браузере «Открой hush. в Telegram» | Так и задумано: приложение работает только внутри Telegram |
| Не пришло уведомление о 5 ответах | Пользователь не разрешил боту писать. Достаточно один раз написать боту `/start` |

**Резервные копии:** все данные лежат в базе Postgres на Railway (вкладка **Backups** у базы).
