# hush. — frontend-прототип

Интерактивный прототип Telegram Mini App **HUSH** (этап 1: дизайн и экраны).
Backend, платежи, база данных и Telegram-авторизация не подключены — все данные демонстрационные, оплата имитируется.

## Запуск

Нужен Node.js 18+.

```bash
cd hush
npm install
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173).
Чтобы открыть с телефона в той же Wi-Fi-сети, используйте адрес `Network: http://192.168.x.x:5173`, который печатает Vite.

Сборка: `npm run build` (проверка TypeScript + production-сборка в `dist/`).

## Меню разработчика

Узкая вкладка с гаечным ключом у левого края экрана (или клавиша <kbd>`</kbd> на компьютере):

- 10 демо-сценариев (новый пользователь, 0/3/7 ответов, подписки 1 мес / 3 мес / год, несколько анкет, режим друга, выключенное автопродление);
- быстрый переход между экранами;
- сброс прототипа.

Состояние сохраняется в `localStorage`, поэтому переживает перезагрузку страницы.

## Структура

```
src/
  design/tokens.ts      дизайн-токены (цвета, шрифты, типографика, радиусы, анимации)
  components/ui/        переиспользуемые компоненты (AppHeader, PrimaryButton, QuestionCard, AnswerCard, PricingCard, BottomSheet, Modal, Toast …)
  components/dev/       меню разработчика
  data/                 вопросы, демо-ответы, тарифы, сценарии
  lib/                  правила доступа к ответам, шаринг, форматирование, обёртка Telegram
  state/                состояние приложения
  screens/              экраны
```

Настройки, которые легко поменять:

- выделенный тариф — `RECOMMENDED_PLAN` в `src/data/pricing.ts`;
- порог открытия результатов и число бесплатно видимых ответов — `src/lib/access.ts`.

## Готово на этом этапе

1. Приветствие (`/`)
2. Выбор вопросов (`/questions`)
3. Главный экран с результатами (`/home`) — бесплатный и Premium-вид; черновые состояния «0 ответов» и «3 из 5»
4. Подписка (`/paywall`) с имитацией оплаты

Экраны следующих этапов временно открывают служебную заглушку «Прототип · Этап N».
