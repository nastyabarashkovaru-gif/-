# hush. — Telegram Mini App

Анонимные анкеты «что о тебе думают друзья». React + TypeScript + Vite + Tailwind CSS + Lucide + Motion.
Дизайн — `design/`: актуальные макеты шрифтов и иконок `design/v2/*.png`, исходные скриншоты `design/screens/*.png`, `design/design-reference.html`, спецификация `design/CLAUDE.md`.

## Запуск локально

Нужен Node.js 18+.

```bash
cd hush
npm install
npm run dev          # http://localhost:5173
```

`npm run build` — проверка TypeScript + production-сборка в `dist/`, `npm run preview` — просмотр сборки.
Открыть ответ «как друг» по ссылке: `http://localhost:5173/?startapp=DEMO`.

## Демо-режим

По умолчанию (`VITE_DEMO=true`, без `VITE_API_URL`) работает локальный mock backend в `localStorage`.
Вкладка **DEMO** у левого края открывает панель:

- сценарии: новый пользователь, ожидание 0/5 и 3/5, результаты 5 / 18 / 50 / 100;
- подписка: нет / 1 месяц / 3 месяца / год (демо-состояние, помечено в настройках);
- «+ Ответ друга» — имитирует нового респондента (на 5-м ответе ожидание сменяется результатами);
- быстрый переход на любой из экранов 01–10b.

Все демо-ответы и имена лежат в `src/demo/seed.ts` и помечены как демонстрационные.
В production: `VITE_DEMO=false` + `VITE_API_URL=https://…` — mock и панель отключаются.

## Платежи

**Не подключены.** Кнопки оплаты, «Восстановить покупку» и переключатель автопродления только показывают
подсказку «Оплата пока недоступна» — никаких провайдеров, списаний и выдачи доступа.
Перед подключением проверьте требования Telegram к цифровым товарам (Telegram Stars).

## Структура

```
src/
  api/        контракт API (types.ts), mock-сервер (mock.ts), HTTP-клиент (http.ts)
  data/       каталог вопросов, тарифы
  demo/       демо-данные и панель DEMO
  lib/        Telegram WebApp, шаринг, плюрализация
  nav/        стек-навигация + нативная кнопка «Назад» Telegram
  state/      bootstrap-состояние, кэш результатов
  ui/         общие компоненты (CTA с анимированной обводкой, прогресс, модалка, тосты)
  screens/    экраны
```

Подключение backend — см. [`docs/BACKEND.md`](docs/BACKEND.md).
