# Конфигурация (меняется в админке без деплоя)

`/admin` → «Конфиги». Изменения пишутся в `admin_audit_log`.

| Ключ | Что это |
|---|---|
| `level_curve` | `{table:[1,2,3,4,5,7,9,12,15,20,25,30,35,40,45,50], tail:{ceiling:90, rate:0.08}}` — `table[i]` = стоимость полива с уровня i+1 на i+2; дальше `cost = last + (ceiling − last)·(1 − e^(−rate·n))`: плавный рост без скачков, мягкий потолок. Цена читается внутри транзакции полива — всегда актуальная. |
| `brand` | рабочее название (`ROSTOK`) и утверждённый слоган |
| `onboarding` | 4 продающих слайда и фраза «Всё начинается с маленького ростка» |
| `paywall` | заголовок, подзаголовок, пункты |
| `notification_texts` | тексты напоминаний (`{sphere}`, `{n}`, `{task}`, `{gift}`) |
| `flags` | `retentionOffer`, `winbackOffer` (по умолчанию выкл.), `challenges`, `reminders` |
| `asset_manifest` | `species.<вид>.<уровень>.{normal,withered}` → URL финального ассета; `island`, `sprout`. Пусто → процедурный SVG (временный арт). Новые уровни добавляются без изменения логики. |

Тарифы: в админке меняются тексты и активность; суммы — только миграцией после настройки провайдера.

## Дизайн-система
Цвета (`web/tailwind.config.ts`): белый `#FFFFFF`, почти белый `#FAFCF9`, зелёный `#78BC8A`, глубокий зелёный `#276B48`, розовый `#F6C6D8`, акцент `#E98CB2`, текст `#26342C`, вторичный текст `#69756E` (AA на белом), декоративный серый `#87918B`, капли `#7BCBF0`.
Радиусы карточек 22 px, кнопок 16 px. Анимации 150–400 мс, полив ≈2.5 с; `prefers-reduced-motion` и переключатель «Меньше анимации» отключают движение.

## Арт
`web/src/art`: процедурные «clay»-деревья (SVG, градиенты, блики), 6 видов, рост по уровням, цветы/плоды, крупные украшения каждые 10 уровней (качели 10, фонарики 20, бабочки 30, свечение 40, звезда 50), единое увядшее состояние, силуэт следующего сюрприза, изометрический остров с декором по уровню сада.
Витрина всех состояний: `/art`. Это **временный арт**: финальные 3D-иллюстрации подключаются через `asset_manifest`.
