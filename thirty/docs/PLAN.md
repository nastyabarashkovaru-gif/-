## Команды проверки

```bash
cd thirty
npm test                                         # домен + сервер (нужен Postgres, база thirty_test)
LOAD=1 npx vitest run test/load.test.ts          # из apps/server: нагрузка 1200 участников
npm run typecheck && npm run build
```

Результат нагрузочного прогона: 1200 участников × 3 цели × 30 дней (108 000 выполнений). Пересчёт рейтинга занимает 3,4 с (фоновая задача раз в 10 минут), `/api/home` — 59 мс, `/api/leaderboard` — 49 мс.
