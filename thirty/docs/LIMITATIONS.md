# Ограничения Telegram и Prodamus и рабочие альтернативы

Принцип: в коде используется только то, что подтверждено документацией или открытыми клиентскими библиотеками. Каждый пункт с пометкой **⚠ проверить в sandbox** нужно один раз проверить на тестовом магазине до продакшена.

## Prodamus

Сайт `help.prodamus.ru` недоступен из среды разработки (сетевая политика). Факты ниже собраны из описаний официальных страниц в поиске и из исходников открытых клиентов (npm `@exode-team/prodamus-ru.api`, gem `prodamus`).

| Возможность | Статус | Как используется |
|---|---|---|
| Ссылка на оплату: GET на `https://<магазин>.payform.ru/` с `do=link` (короткая ссылка) или `do=pay` | подтверждено | `ProdamusProvider.createPaymentLink` |
| Параметры `order_id`, `customer_extra`, `urlNotification`, `urlSuccess`, `urlReturn`, `link_expired`, `products[i][…]`, `subscription=<id>`, `subscription_date_start`, `subscription_demo_period`, `subscription_limit_autopayments`, `_param_*`, `callbackType=json`, `payments_limit` | подтверждено (типы клиента) | заказ на подписку передаёт `subscription` и наш `order_id` |
| Подпись: HMAC-SHA256 от JSON, где ключи рекурсивно отсортированы, значения приведены к строкам, `/` экранирован как `\/`, юникод не экранирован | подтверждено (идентично в двух клиентах) | `prodamus/sign.ts` + тест |
| Webhook: подпись в HTTP-заголовке `Sign`, тело `application/x-www-form-urlencoded` с вложенными ключами; поля `order_id`, `order_num`, `sum`, `payment_status` (`success`, `order_denied`, `order_canceled`), `products`, `customer_extra` | подтверждено | `/api/payments/prodamus/webhook` |
| Подписки: создаются **в личном кабинете** Prodamus (сумма и период задаются там), в ссылку передаётся их числовой id | подтверждено | у каждого тарифа в админке поле «ID подписки Prodamus» |
| `POST /rest/setActivity/`: включить или выключить подписку покупателя (флаги менеджера и пользователя) | подтверждено (официальная страница существует) | отмена автопродления |
| `POST /rest/setSubscriptionPaymentDate/`: перенести дату следующего списания | подтверждено, **только на более позднюю дату**, не в прошлое и не раньше текущей запланированной | перенос на 28-е число |
| После окончания подписки любые изменения через API запрещены | подтверждено | при ошибке пометка `provider_locked` и ручная обработка |
| Списание по инициативе продавца произвольной суммы через API | **не найдено** | не используется: все повторные списания делает сама подписка Prodamus |
| Возврат через API | **не найдено** | возврат делается в кабинете Prodamus, в админке кнопка «Отметить возврат» с журналом; если придёт webhook о возврате, он обработается автоматически |
| Повторные попытки после неуспешного списания | **⚠ настраиваются в кабинете Prodamus** | своих повторных списаний мы не делаем; 29–30 числа шлём уведомление и даём ручную оплату долга отдельной ссылкой |
| Точные поля webhook о рекурренте (`subscription[...]`) | **⚠ проверить в sandbox** | парсер принимает и плоский, и вложенный формат и сохраняет сырое тело в `PaymentEvent` |

### Как получается «списание 28-го числа»

Подписка Prodamus списывает с периодом от даты первой оплаты. Схема такая:

1. Первая оплата идёт сразу при покупке и покрывает N ближайших потоков.
2. После webhook `success` сервер вызывает `setSubscriptionPaymentDate` и ставит дату следующего списания на 28-е число последнего оплаченного месяца (покупка 21.10 на 3 месяца: естественная дата Prodamus 21.01, переносим на 28.01).
3. **Ограничение:** перенос возможен только вперёд. Если покупка была 29–31 числа, естественная дата (29–31 число последнего месяца) уже позже 28-го. Тогда оставляем её. Списание всё равно проходит до старта следующего потока, и эта дата показывается пользователю до оплаты. Логика в `domain/billing.ts → providerChargeDate`.
4. Если у Prodamus нет нужного периода (например, 6 месяцев), владелец создаёт подписку с этим периодом в кабинете. **⚠ проверить, что период 3 и 6 месяцев доступен.**

### Цена продления

Сумма повторного списания равна сумме, настроенной в подписке Prodamus. Поэтому для каждого тарифа в админке есть два id подписки: «акционная» (первый платёж по акционной цене) и «обычная». Цена продления показывается до оплаты из поля тарифа `renewalPrice`, и она обязана совпадать с суммой в кабинете (сервер это не проверит, только админ). Какую цену брать при продлении, решает владелец, см. QUESTIONS.md.

## Telegram

| Возможность | Статус | Решение |
|---|---|---|
| Бот создаёт группу | **недоступно в Bot API** | группу потока создаёт админ вручную и добавляет бота админом (права: приглашать и ограничивать участников); в админке A05/A11 привязывается `chat_id` (бот присылает id группы командой `/bind` от админа) |
| Персональная ссылка-приглашение | `createChatInviteLink` с `creates_join_request=true`, `expire_date`, `name` | пользователь подаёт заявку, бот получает `chat_join_request`, проверяет оплату и вызывает `approveChatJoinRequest` или `declineChatJoinRequest`. Пересланная ссылка бесполезна без оплаты |
| Удалить участника после окончания прав | `banChatMember` + сразу `unbanChatMember` (кик без вечного бана) | при новой оплате выдаётся новая ссылка |
| Писать пользователю первым | только если он сам писал боту или дал разрешение (`requestWriteAccess` в Mini App, `allows_write_to_pm`) | `User.allowsWrite`; рекламные цепочки дополнительно требуют `marketing` opt-in. Ошибка 403 → `botBlocked=true`, отправки прекращаются |
| Лимиты отправки | около 30 сообщений в секунду всего, около 1 в секунду в один чат, 20 в минуту в группу | очередь с ограничением 25/с и обработкой `retry_after` при 429 |
| Deep link в Mini App | `https://t.me/<bot>/<app>?startapp=<param>` (до 512 символов, `A-Za-z0-9_-`) | возврат на нужный экран, рефералы, бадди-инвайты |
| Поделиться карточкой | `shareToStory` (Bot API 7.8+, ссылка-виджет только у Premium-пользователей), `downloadFile` (8.0+), `shareMessage` (подготовленное сообщение) | кнопки «Сохранить» и «Поделиться»; публикацию во внешней соцсети мы **не видим**, считаем только клик `share_clicked` |
| Реальный просмотр сторис Instagram | недоступен | не заявляется в аналитике |
| Видеосозвоны | в Bot API нет | `joinUrl` (Zoom, Telemost, видеочат группы) задаётся экспертом в админке |

## Прочее

- Перечёркнутые цены: в ТЗ 1.1 сравнение подписано как «стоимость отдельных месяцев» (2990 × N), а не как прежняя цена пакета.
- Случайная жеребьёвка денежного приза при платном участии требует юридической оценки: функция выключена фичефлагом `prize_random_draw` и не включается без решения.
- Онлайн-касса (54-ФЗ): чеки формирует Prodamus, если это подключено в кабинете. **⚠ проверить у владельца.**
